# Склад пластика для 3D печати

Учёт катушек пластика для 3D печати. Расчет стоимости моделей.

## Возможности

- Просмотр текущего склада
- Списать пластик на печать модели
- Рассчитать стоимость печати (без списания)
- Пополнить катушку
- Стоимость всего склада
- Остаток по материалу
- Пластика израсходовано
- Добавить катушку
- Удалить катушку
- Удалить пустые катушки
- Заканчивающиеся катушки
- Отчет по материалам
- Потребность в пополнении
- Отчет об использованном пластике
- Журнал списаний по материалам

## Как запустить

Нужен JDK 21 (например, Amazon Corretto 21).

1) в IntelliJ IDEA — запустить класс Main
2) из терминала — команды компиляции и запуска

```
   javac -d out src/*.java
   java -cp out Main
```

## Как запустить тесты

Проверка основного функционала склада, проверка крайних значений.
Результат ✅, если тест пройден и ❌, если что-то не работает.
Нужен JDK 21 (например, Amazon Corretto 21).

1) в IntelliJ IDEA — запустить класс SpoolTest.java
2) из терминала — команды компиляции и запуска

```
   javac -d out src/*.java
   java -cp out SpoolTest
``` 

## Сборка и запуск JAR

```
    javac -d out src/*.java
    jar --create --file warehouse.jar --main-class Main -C out .
    java -jar warehouse.jar
```
Для запуска тестов:
```
    java -cp warehouse.jar SpoolTest            
```
Если в консоли Windows вместо русских букв видны «кракозябры», переключите консоль на UTF-8 перед запуском: `chcp 65001`. 
В PowerShell дополнительно: 
`[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`

## Устройство проекта

- `Spool` — Класс катушка, материал цвет, остаток пластика и цена за кг
- `Warehouse` — Склад, содержит катушки и методы для расчета по складу
- `Main` — Меню и вывод на экран
- `SpoolTest` — Тестирование основного функционала
- `WriteOff` — запись журнала списаний (материал, цвет, граммы, цена за кг).
